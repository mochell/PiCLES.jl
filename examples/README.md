# PiCLES examples

This folder contains user-facing runnable scenarios.

## Current examples

- `example_01_single_particle_1d.jl`: single-particle 1D setup.
- `example_02_single_particle_2d.jl`: single-particle 2D setup.
- `example_03_single_particle_2d_rk35_solver.jl`: 2D single-particle run with RK35 solver focus.
- `example_04_single_particle_2d_local_winds.jl`: 2D single-particle run with time-varying local winds.

These are long-form scenario scripts and are not used directly by `runtests.jl`.
